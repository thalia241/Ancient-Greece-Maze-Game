# Python Maze Game

A simple maze game built with Python. The player navigates through an ancient Greece-themed maze to reach the goal.

## Features
- Player movement with arrow keys
- Randomized maze layouts
- Win condition detection
- Clean OOP structure

## Why This Matters
Demonstrates strong **Python fundamentals**, including:
- Object-oriented design
- Game loop structure
- User input handling

## Tech Stack
- Python (3.11+)
- Tkinter for graphics

git clone https://github.com/thalia241/python-maze-game.git
